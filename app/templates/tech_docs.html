01Обзор

Fokin System — приложение для знакомств и общения: друзья, публикации, объявления, чаты и колокольчик уведомлений. Backend на FastAPI, клиент на React Native (Expo).

02Backend

  • app/api/routers/: users (профиль, поиск, друзья), feed и news (публикации, новости, объявления), chat и group_chat (сообщения), notification_center (колокольчик), notifications (WebSocket), ai, admin, tasks.
  • Веб-страницы и статика отдаются из app/main.py. Медиа — через /media/*.

03Push и счётчики

  • Все события колокольчика создаются через create_or_group_notification(); однотипные события группируются по group_key.
  • Android получает только data-сообщение с высоким приоритетом, его показывает Notifee с аватаркой отправителя. iOS — APNs.
  • Поле data.type задаёт маршрут: new_message, new_group_message → счётчик сообщений; friend_request, friend_accepted, announcement, new_post и неизвестные типы → колокольчик.
  • Счётчики независимы: колокольчик — /notifications/unread-count, сообщения — unread_count диалогов.
  • Тихие часы отправляют push без звука (канал silent). Отключаемые группы задаются в настройках пользователя; объявления отключить нельзя.

04Схема потока

Нажмите на узел, чтобы увидеть описание этапа.

→ → → → → →

Событие

Роутер фиксирует действие: лайк, заявку в друзья, объявление, сообщение.

Сервис

create_or_group_notification() создаёт запись или обновляет непрочитанную с тем же group_key.

База данных

Запись сохраняется до доставки, поэтому колокольчик показывает историю даже без push.

Диспетчер

dispatch_notification() проверяет группу, токен устройства и тихие часы.

WebSocket

Если приложение открыто, событие приходит сразу, без опроса.

FCM / APNs

Firebase Admin SDK отправляет сообщение: Android — data-only, iOS — alert + data.

Клиент

Фоновый обработчик получает data-сообщение, Notifee показывает одно уведомление в нужном канале.

05Мобильное приложение

  • Expo SDK 54, React Native 0.81, React Navigation 7.
  • Push: @react-native-firebase/messaging и @notifee/react-native. Каналы: messages и silent.
  • Переход по тапу — единая функция navigateByPushData по data.type.
