01Назначение

Foxly — личный журнал, который можно сделать публичным, со social-лентой, чатами и ИИ-помощником по записям. Backend написан на FastAPI, мобильный клиент — на React Native (Expo).

02Запуск

  1. Скопируйте переменные окружения в файл .env и заполните свои значения. Файл в git не коммитится.
  2. Поднимите сервисы командой ниже. Для локального запуска используйте docker-compose.yml.
  3. Откройте сайт в браузере. Проверка работы: главная страница отвечает без ошибок.
docker compose -f docker-compose.yml up --build
Ollama

Для ИИ-помощника на хосте должен работать Ollama. Адрес и модель задаются в .env (OLLAMA_URL, OLLAMA_MODEL).

03Основные разделы

  • API. Роутеры лежат в app/api/routers/: users, feed, news, chat, group_chat, notification_center, notifications (WebSocket), ai, admin, tasks.
  • Страницы. Шаблоны Jinja2 находятся в app/templates/, статика — в app/static/. Медиа отдаются через /media/*.
  • Уведомления. Все события колокольчика создаются через create_or_group_notification() и группируются по group_key. Тихие часы отправляют push без звука.
  • Счётчики. Колокольчик — /notifications/unread-count, сообщения — непрочитанные диалоги. Они независимы.
  • Мобильное приложение. Expo SDK 54, React Native 0.81. Push: Firebase Messaging и Notifee (Android), APNs (iOS).

04Частые вопросы

Где хранятся секреты?

В переменных окружения (.env). В шаблонах и скриптах их быть не должно.

Почему ИИ не отвечает?

Проверьте, что Ollama запущен и слушает нужный адрес, а модель из OLLAMA_MODEL загружена.

Как поменять название сайта?

Название задано в начале index.html в переменной SITE_NAME.
