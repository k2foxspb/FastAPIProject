# Руководство пользователя приложения

Это руководство написано простым языком и предназначено для всех сотрудников компании, которые пользуются мобильным приложением. Здесь нет технических терминов — только пошаговые инструкции по работе с документами, табелем, уведомлениями и другими разделами.

Руководство разбито на части по ролям. Найдите свою роль и читайте соответствующий раздел. Если вы выполняете несколько ролей (например, руководитель и одновременно подписант), прочитайте все подходящие вам разделы.

## 1. Краткая памятка для быстрого старта

| Что нужно сделать | Куда идти |
|---|---|
| Создать и отправить документ | Раздел «Документы» → «Создать документ» |
| Согласовать документ как подписант | Раздел «Мне на подпись» |
| Подтвердить, что ознакомились с документом | Раздел «Мои документы» |
| Посмотреть, кто ознакомился с документом | Откройте документ → «Отчёт по ознакомлению» |
| Отправить повторное напоминание | Отчёт по ознакомлению → фильтр «Не ознакомились» → «Отправить повторное уведомление» |
| Заполнить табель | Раздел «Табель» |
| Посмотреть уведомления | Значок колокольчика / раздел «Уведомления» |
| Получить помощь в поиске нужного раздела | Чат с ИИ-ассистентом |

> **Важно.** Если какого-то пункта меню нет на вашем экране — скорее всего, у вашей роли нет прав на это действие. Обратитесь к администратору или своему руководителю.

## 2. Инструкция для руководителя

Руководитель — это пользователь, который может создавать документы, назначать подписантов и отправлять документы сотрудникам на ознакомление (например, начальник цеха, начальник отдела, мастер).

### 2.1. Раздел «Документы»

**Как открыть раздел документов**
1. Откройте нижнее меню приложения.
2. Перейдите в раздел «Документы» (он находится в профиле или в отдельной вкладке, в зависимости от настроек меню).

**Как создать категорию или папку документов**
1. В разделе «Документы» нажмите кнопку «Создать категорию» (обычно обозначена значком «+»).
2. Введите название категории (например, «Приказы», «Инструкции по охране труда»).
3. Сохраните категорию.

**Как отредактировать категорию**
1. Найдите нужную категорию в списке.
2. Нажмите на неё и выберите «Редактировать» (или значок карандаша).
3. Измените название и сохраните изменения.

**Как удалить категорию**
1. Откройте категорию, которую нужно удалить.
2. Выберите действие «Удалить».
3. Подтвердите удаление.

> **Важно.** Если в категории есть документы, их удаление может быть ограничено — система предупредит вас об этом.

**Как создать документ**
1. Откройте нужную категорию или нажмите «Создать документ» в общем списке.
2. Заполните форму документа (см. ниже).
3. Сохраните документ как черновик или сразу отправьте его дальше.

**Как заполнить название документа**
- В поле «Название» укажите короткое и понятное название, по которому сотрудники сразу поймут, о чём документ (например, «Инструктаж по пожарной безопасности»).

**Как выбрать категорию**
- В выпадающем списке «Категория» выберите подходящую папку. Если нужной категории нет — создайте её заранее (см. выше).

**Как добавить описание**
- В поле «Описание» кратко опишите суть документа — зачем он нужен и что должен сделать сотрудник.

**Как прикрепить файл или заполнить текст документа**
- Нажмите «Прикрепить файл», чтобы загрузить фото, скан или файл документа.
- Либо используйте поле «Текст документа», если документ достаточно показать прямо в приложении без отдельного файла.
- Можно использовать оба варианта одновременно.

**Как указать текст кнопки подтверждения**
1. В поле «Текст кнопки подтверждения» введите формулировку, с которой сотрудник подтвердит ознакомление.
2. Примеры: «Ознакомлен», «Проинструктирован», «Подтверждаю», «Прочитал».
3. Если оставить поле пустым, будет использована стандартная надпись «Ознакомлен».

> **Примечание.** Текст кнопки можно подбирать под тип документа: для инструктажей — «Проинструктирован», для приказов — «Ознакомлен», для согласий — «Подтверждаю».

**Как выбрать подписантов для согласования документа**
1. В разделе «Подписанты» нажмите «Добавить подписанта».
2. Выберите одного или нескольких сотрудников, которые должны согласовать документ перед отправкой.
3. Если согласование не требуется — просто не добавляйте подписантов.

**Как сохранить документ как черновик**
- Нажмите кнопку «Сохранить черновик». Документ не будет виден сотрудникам и подписантам, пока вы не отправите его дальше.

**Как отправить документ на согласование**
1. Проверьте, что добавлены подписанты.
2. Нажмите кнопку «Отправить на согласование».
3. Документ перейдёт в статус «На согласовании», и подписанты получат уведомление.

**Как понять текущий статус документа**

| Статус | Что означает |
|---|---|
| Черновик | Документ создан, но ещё не отправлен никуда |
| На согласовании | Документ ждёт решения подписантов |
| Согласован | Все подписанты одобрили документ, можно отправлять на ознакомление |
| Отклонён | Хотя бы один подписант отклонил документ, нужны правки |
| Отправлен на ознакомление | Документ разослан сотрудникам, идёт сбор подтверждений |
| Архивный | Документ больше не активен, хранится для истории |

### 2.2. Согласование документа

**Как посмотреть, кто должен согласовать документ**
- Откройте документ → вкладка/блок «Согласование». Там отображается полный список назначенных подписантов.

**Как узнать, кто уже согласовал / кто ещё не согласовал**
- В том же блоке «Согласование» напротив каждого подписанта показан его статус: «Согласовал», «Отклонил» или «Ожидает решения».

**Как посмотреть комментарии подписантов**
- Если подписант оставил комментарий (например, при отклонении), он отображается рядом с его именем в блоке согласования.

**Что делать, если документ отклонён**
1. Откройте документ и посмотрите комментарий подписанта, который его отклонил.
2. Внесите нужные правки в документ (текст, файл, описание).
3. Отправьте документ на повторное согласование.

**Как отредактировать отклонённый документ**
1. Откройте отклонённый документ.
2. Нажмите «Редактировать».
3. Внесите изменения и сохраните.

**Как повторно отправить документ на согласование**
- После правок нажмите «Отправить на согласование повторно». Все подписанты снова получат документ на рассмотрение.

**Как отправить напоминание подписантам, которые ещё не согласовали документ**
- В блоке «Согласование» рядом с подписантами в статусе «Ожидает решения» нажмите «Напомнить» (или аналогичную кнопку).

### 2.3. Отправка документа на ознакомление

**Когда документ можно отправить на ознакомление**
- Если согласование не требовалось — сразу после создания документа.
- Если согласование требовалось — только после того, как документ получил статус «Согласован».

**Что делать, если документ ещё не согласован**
- Дождитесь решения всех подписантов. Отправить документ на ознакомление раньше нельзя — кнопка отправки будет недоступна или появится предупреждение.

**Как выбрать получателей**
1. Откройте согласованный документ (или документ без согласования).
2. Нажмите «Отправить на ознакомление» → «Выбрать получателей».
3. Выберите один из вариантов:
   - весь цех;
   - отдел;
   - отдельные сотрудники.

**Как проверить выбранных получателей перед отправкой**
- Перед отправкой приложение покажет итоговый список сотрудников, которым будет отправлен документ. Проверьте его внимательно.

**Как отправить документ**
- Нажмите кнопку «Отправить». Документ перейдёт в статус «Отправлен на ознакомление».

**Что увидят сотрудники после отправки документа**
- Сотрудники получат уведомление о новом документе, а сам документ появится в их разделе «Мои документы» со статусом «Ожидает ознакомления».

### 2.4. Отчёт по ознакомлению

**Как открыть отчёт по документу**
- Откройте нужный документ и перейдите в блок/вкладку «Отчёт по ознакомлению».

**Как посмотреть общий прогресс ознакомления**
- В верхней части отчёта отображается общее количество получателей и сколько из них уже ознакомились (например, «7 из 12»).

**Как увидеть список сотрудников, которым отправлен документ**
- Список всех получателей отображается в самом отчёте.

**Как узнать, кто ознакомился / кто не ознакомился**
- Рядом с каждым сотрудником указан его статус: «Ознакомлен» или «Ожидает ознакомления».

**Как посмотреть дату и время ознакомления**
- Для сотрудников со статусом «Ознакомлен» рядом отображается дата и время подтверждения.

**Как использовать фильтры**
- В верхней части отчёта доступны фильтры:
  - «Все» — показать всех получателей;
  - «Ознакомились» — только тех, кто подтвердил;
  - «Не ознакомились» — только тех, кто ещё не подтвердил;
  - «По отделу» / «По цеху» — отфильтровать по подразделению.

**Как отправить повторное уведомление тем, кто не ознакомился**
1. Включите фильтр «Не ознакомились».
2. Нажмите «Отправить повторное уведомление».
3. Уведомление придёт только тем сотрудникам, которые ещё не подтвердили ознакомление.

### 2.5. Уведомления для руководителя

Руководитель получает уведомления:
- о решении подписанта (согласовал/отклонил документ);
- об отклонении документа — с указанием, кто отклонил и почему;
- о завершении согласования (когда все подписанты одобрили документ);
- о необходимости выполнить действие (например, документ готов к отправке на ознакомление).

**Как понять, что нужно выполнить действие**
- Такие уведомления обычно содержат понятный призыв к действию (например, «Документ согласован, отправьте его сотрудникам»). Нажмите на уведомление, чтобы сразу перейти к документу.

## 3. Инструкция для подписанта

Подписант — это сотрудник, назначенный руководителем для согласования конкретного документа.

**Как открыть список документов на согласование**
1. Перейдите в раздел «Мне на подпись» (или «Документы на согласование»).
2. Вы увидите список всех документов, которые ожидают вашего решения.

**Как понять, какие документы ожидают решения**
- В списке отображаются только те документы, по которым вы ещё не приняли решение. Как только вы согласуете или отклоните документ, он пропадёт из этого списка (если не потребуется повторное согласование).

**Как открыть документ**
- Нажмите на документ в списке, чтобы открыть его полностью.

**Как посмотреть название, описание, категорию, файл или текст документа**
- Вся эта информация показана на экране документа: сверху — название и категория, ниже — описание, далее — прикреплённый файл или текст.

**Как посмотреть автора документа**
- Автор документа (кто его создал) указан в верхней части экрана документа.

**Как согласовать документ**
1. Внимательно изучите содержимое документа.
2. Если замечаний нет, нажмите кнопку «Согласовать».

**Как отклонить документ**
1. Нажмите кнопку «Отклонить».
2. Укажите причину отклонения в поле комментария.
3. Подтвердите отклонение.

**Когда нужно оставить комментарий**
- При согласовании комментарий обычно необязателен (но его можно оставить, если есть пожелания).
- При отклонении комментарий обязателен.

**Почему при отклонении комментарий обязателен**
- Автор документа должен понимать, что именно нужно исправить. Без комментария он не сможет внести правильные правки.

**Что происходит после согласования**
- Ваше решение фиксируется. Если все подписанты согласовали документ, он переходит в статус «Согласован», и автор документа может отправлять его на ознакомление.

**Что происходит после отклонения**
- Документ получает статус «Отклонён». Автор увидит ваш комментарий, внесёт правки и сможет отправить документ на повторное согласование.

**Можно ли изменить решение после согласования или отклонения**
- Как правило, уже принятое решение изменить нельзя. Если вы ошиблись, обратитесь к автору документа — он может отправить документ на новое согласование после правок.

**Как действовать, если пришло повторное согласование после правок**
- Это новый документ (или новая версия документа) для рассмотрения. Внимательно ознакомьтесь с изменениями и повторно примите решение — согласовать или отклонить.

## 4. Инструкция для сотрудника

Этот раздел — для всех сотрудников, которым документы назначены на ознакомление.

**Как открыть личную папку документов**
- Перейдите в раздел «Мои документы» (или «Документы для ознакомления»).

**Как увидеть список назначенных документов**
- Все документы, которые вам отправили на ознакомление, отображаются в этом разделе списком.

**Как понять статус документа**

| Статус | Что означает |
|---|---|
| Ожидает ознакомления | Вы ещё не подтвердили, что ознакомились с документом |
| Ознакомлен | Вы уже подтвердили ознакомление |

**Как открыть документ**
- Нажмите на документ в списке.

**Как прочитать текст документа или открыть прикреплённый файл**
- Текст документа отображается прямо на экране. Если приложен файл — нажмите на него, чтобы открыть или скачать.

**Как нажать кнопку подтверждения**
- В конце экрана документа находится кнопка подтверждения. Нажмите на неё после того, как ознакомились с содержимым.

**Почему текст кнопки может отличаться**
- Руководитель сам указывает текст кнопки при создании документа — например, «Ознакомлен», «Проинструктирован», «Подтверждаю» или другое название. Суть одна: нажатие означает, что вы прочитали и поняли документ.

**Что происходит после нажатия кнопки**
- Статус документа меняется на «Ознакомлен», фиксируются дата и время подтверждения, а руководитель видит это в своём отчёте.

**Где посмотреть дату ознакомления**
- Дата и время отображаются рядом со статусом «Ознакомлен» на экране документа.

**Что делать, если документ уже был подтверждён**
- Повторно подтверждать не нужно — документ останется в статусе «Ознакомлен», и вы можете просто посмотреть его содержимое в любое время.

**Что делать, если пришло повторное уведомление**
- Если вы ещё не ознакомились с документом, откройте его и подтвердите ознакомление. Если вы уже подтвердили ранее, повторное уведомление можно просто закрыть — ваш статус не изменится.

## 5. Инструкция для администратора

Этот раздел — для пользователей с ролью администратора.

**Как управлять категориями документов**
- Администратор может создавать, редактировать и удалять любые категории документов, независимо от того, кто их создал.

**Как просматривать все документы**
- В административном разделе доступен просмотр всех документов в системе, включая черновики других руководителей (если это предусмотрено настройками доступа).

**Как помогать пользователям при ошибках**
- Если пользователь сообщает о проблеме (например, не видит документ или не может его согласовать), администратор может открыть документ, проверить список получателей/подписантов и статус, чтобы понять причину.

**Как проверять права доступа**
- Администратор может посмотреть роль пользователя и его подразделение (цех, отдел), чтобы убедиться, что доступ к разделу настроен верно.

**Как управлять пользователями, отделами и цехами**
- В разделе «Пользователи» администратор может добавлять, редактировать сотрудников, назначать им роли, а также управлять структурой подразделений (цехов, отделов), если эта функция доступна в приложении.

**Как просматривать отчёты по документам**
- Если это разрешено, администратор может открывать отчёт по ознакомлению для любого документа, а не только для документов, которые он создал сам.

**Как контролировать корректность назначений**
- Периодически проверяйте, что документы отправлены правильным получателям, а подписанты назначены корректно. Это особенно важно для документов по охране труда и инструктажей.

## 6. Инструкция по ведению табеля

**Где находится раздел табеля**
- Откройте раздел «Табель» в нижнем меню приложения.

**Кто имеет право вести табель**
- Табель ведут руководители и ответственные сотрудники (например, мастера, начальники участков), которым предоставлен доступ к своим подчинённым.

**Как выбрать период**
- В верхней части раздела «Табель» выберите нужный месяц (или другой период), используя стрелки или календарь.

**Как выбрать подразделение, отдел или цех**
- Если вы отвечаете за несколько подразделений, выберите нужное в выпадающем списке в верхней части экрана.

**Как найти сотрудника в табеле**
- Используйте строку поиска или список сотрудников — он обычно отсортирован по фамилии или по участку.

**Как заполнить рабочие дни**
1. Найдите нужного сотрудника и нужный день в таблице.
2. Укажите количество отработанных часов.

**Как отметить выходной, отсутствие, отпуск, больничный или командировку**
- Вместо количества часов за день можно указать текстовую отметку. В приложении есть готовые варианты («Больничный лист», «Отпуск», «Отгул», «Выходной»), либо можно ввести свой текст (например, «Командировка»).

**Как указать переработку или дополнительные часы**
- Если такая функция предусмотрена, укажите фактическое количество отработанных часов за день, включая переработку, в том же поле часов.

**Как сохранить табель**
- Изменения по каждому дню сохраняются автоматически после ввода значения (поле теряет фокус) или по нажатию отдельной кнопки сохранения, если она предусмотрена экраном.

**Как проверить заполненные данные**
- Просмотрите таблицу по строкам (сотрудники) и столбцам (дни), чтобы убедиться, что все рабочие дни заполнены, а отметки (отпуск/больничный/выходной) расставлены верно.

**Как отредактировать уже заполненный табель**
- Нажмите на нужную ячейку (день сотрудника) и измените значение. Редактирование может потребовать повторного согласования, если табель уже был отправлен.

**Как отправить табель на согласование**
- Если в приложении предусмотрено согласование, после заполнения нажмите «Отправить на согласование». Табель будет направлен вышестоящему руководителю (или нескольким руководителям).

**Как понять статус табеля**

| Статус | Что означает |
|---|---|
| Черновик | Данные ещё заполняются, не отправлены на согласование |
| Заполнен | Все необходимые данные внесены |
| На согласовании | Табель отправлен руководителю и ждёт решения |
| Согласован | Табель одобрен |
| Отклонён | Табель отклонён, требуются исправления |

**Как исправить табель после отклонения**
1. Посмотрите комментарий руководителя, который отклонил табель.
2. Внесите необходимые исправления.
3. Отправьте табель на повторное согласование.

**Как выгрузить или распечатать табель**
- Если эта функция предусмотрена в приложении, воспользуйтесь кнопкой «Выгрузить» или «Печать» на экране табеля.

## 7. Инструкция по уведомлениям

**Где пользователь видит уведомления**
- Уведомления отображаются в разделе «Уведомления» (значок колокольчика), а также могут приходить как всплывающие push-уведомления на телефон.

**Какие бывают уведомления**

| Уведомление | Когда приходит |
|---|---|
| Новый документ | Вам отправили документ на ознакомление |
| Документ на согласование | Вас назначили подписантом документа |
| Повторное напоминание | Руководитель напомнил вам об ознакомлении или согласовании |
| Отклонение документа | Подписант отклонил документ, который вы создали |
| Завершение согласования | Все подписанты одобрили документ |

**Как перейти из уведомления к нужному экрану**
- Нажмите на уведомление — приложение автоматически откроет соответствующий документ или раздел.

**Что делать, если уведомление пришло повторно**
- Если действие уже выполнено (документ согласован/ознакомление подтверждено), повторное уведомление можно просто закрыть. Если действие ещё не выполнено — используйте уведомление, чтобы перейти к документу и завершить его.

## 8. Типовые сценарии

### Сценарий 1. Руководитель создаёт документ и отправляет его на ознакомление без согласования
1. Откройте раздел «Документы».
2. Нажмите «Создать документ».
3. Заполните название, категорию и описание.
4. Прикрепите файл или добавьте текст документа.
5. Укажите текст кнопки подтверждения.
6. Не выбирайте подписантов, если согласование не требуется.
7. Выберите получателей.
8. Отправьте документ.
9. Откройте отчёт и отслеживайте ознакомление.

### Сценарий 2. Руководитель создаёт документ с согласованием
1. Откройте раздел «Документы».
2. Нажмите «Создать документ».
3. Заполните данные документа.
4. Выберите подписантов.
5. Нажмите «Отправить на согласование».
6. Дождитесь согласования всеми подписантами.
7. После согласования выберите получателей.
8. Отправьте документ на ознакомление.
9. Контролируйте статус ознакомления в отчёте.

### Сценарий 3. Подписант согласует документ
1. Откройте раздел «Мне на подпись».
2. Выберите документ.
3. Ознакомьтесь с содержимым.
4. Нажмите «Согласовать», если замечаний нет.
5. Если есть замечания, нажмите «Отклонить» и укажите комментарий.

### Сценарий 4. Сотрудник подтверждает ознакомление
1. Откройте раздел «Мои документы».
2. Выберите документ со статусом «Ожидает ознакомления».
3. Ознакомьтесь с документом.
4. Нажмите кнопку подтверждения.
5. Убедитесь, что статус изменился на «Ознакомлен».

### Сценарий 5. Руководитель отправляет повторное уведомление
1. Откройте документ.
2. Перейдите в отчёт по ознакомлению.
3. Отфильтруйте сотрудников со статусом «Не ознакомились».
4. Нажмите «Отправить повторное уведомление».
5. Убедитесь, что напоминание отправлено только тем, кто ещё не ознакомился.

### Сценарий 6. Ответственный ведёт табель
1. Откройте раздел «Табель».
2. Выберите период.
3. Выберите подразделение или отдел.
4. Заполните данные по сотрудникам.
5. Проверьте корректность отметок.
6. Сохраните табель.
7. При необходимости отправьте табель на согласование.

## 9. Частые вопросы

**Почему я не могу отправить документ на ознакомление?**
Скорее всего, документ ещё не прошёл согласование у всех подписантов. Дождитесь статуса «Согласован» — после этого кнопка отправки станет доступна.

**Почему документ находится в статусе «На согласовании»?**
Это означает, что хотя бы один из назначенных подписантов ещё не принял решение. Посмотрите в блоке согласования, кто именно не ответил, и при необходимости отправьте ему напоминание.

**Что делать, если подписант отклонил документ?**
Посмотрите комментарий подписанта, внесите необходимые правки в документ и отправьте его на повторное согласование.

**Можно ли изменить документ после отправки?**
Документ, отправленный на ознакомление, обычно редактировать нельзя — слишком сильно изменился бы его смысл для тех, кто уже с ним ознакомился. Если нужно внести изменения, создайте новую версию документа или новый документ.

**Почему сотрудник не видит документ?**
Проверьте, что сотрудник действительно включён в список получателей (весь цех, отдел или конкретный человек). Если документ ещё не отправлен (находится в черновике или на согласовании), сотрудники его не увидят.

**Что делать, если сотрудник не нажал кнопку ознакомления?**
Откройте отчёт по ознакомлению, отфильтруйте сотрудников со статусом «Не ознакомились» и отправьте им повторное уведомление.

**Как отправить повторное уведомление?**
Откройте документ → «Отчёт по ознакомлению» → фильтр «Не ознакомились» → кнопка «Отправить повторное уведомление».

**Почему кнопка подтверждения называется по-разному?**
Текст кнопки задаёт руководитель при создании документа — он может выбрать формулировку, подходящую под тип документа («Ознакомлен», «Проинструктирован», «Подтверждаю» и т.д.).

**Где посмотреть дату ознакомления?**
Дата и время ознакомления отображаются в отчёте по документу рядом с именем сотрудника, а также на экране самого документа у сотрудника, который его подтвердил.

**Кто видит отчёт по документу?**
Отчёт видит автор документа (руководитель), а также администратор, если у него есть доступ к просмотру всех документов.

**Как исправить ошибку в табеле?**
Откройте нужный день сотрудника в табеле и измените значение. Если табель уже отправлен на согласование и отклонён, посмотрите комментарий и внесите исправления, затем отправьте табель повторно.

**Можно ли изменить табель после сохранения?**
Да, пока табель не согласован окончательно, данные можно редактировать. После согласования изменения могут потребовать повторной отправки на согласование.

## 10. Помощник-поиск (ИИ-ассистент)

Если вы не можете найти нужный раздел приложения, воспользуйтесь встроенным ИИ-ассистентом (чат-помощником):

1. Откройте чат с ассистентом.
2. Опишите словами, что вы хотите найти (например, «где посмотреть отчёт по документу» или «где заполнить табель»).
3. Ассистент ответит на русском языке и, если найдёт подходящий раздел, добавит в ответ ссылку — нажмите на неё, чтобы сразу перейти в нужный раздел приложения.

> **Примечание.** Ассистент помогает ориентироваться в приложении и отвечает на общие вопросы по работе с его разделами. Для вопросов о конкретных документах или ваших персональных данных обращайтесь к своему руководителю или администратору.
